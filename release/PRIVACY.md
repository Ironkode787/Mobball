# KINGPIN closed-beta privacy disclosure

KINGPIN does not include advertising, third-party analytics, account login, or networking. It
does not automatically send gameplay or personal data anywhere.

Closed-beta players may explicitly allow optional on-device funnel telemetry in House Rules.
When allowed, the game stores a small, capped list of coarse progress milestones such as opening
Roll Call, starting or completing a Night, first launch, first active earning, opening the
Ledger, buying an upgrade, and starting or completing a Raid.

The report does not contain a name, account, advertising ID, device or install identifier, IP
address, location, locale, contact information, exact currency balance, absolute timestamp,
free-form text, or crash stack. Session time and gameplay counts are bucketed. Nothing is
uploaded automatically.

Players can copy/export the report for voluntary sharing, clear local beta data, or turn the
feature off and clear it. Turning it off does not affect career progress or accessibility/audio
settings. Uninstalling the app removes locally stored data because Android backup is disabled.

This repository text is a product disclosure draft, not a substitute for completing the current
Google Play Data safety form and publishing a hosted privacy-policy URL before track rollout.
