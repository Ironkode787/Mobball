# Closed-beta device matrix

| Tier | Required profile | Acceptance |
|---|---|---|
| Minimum | Android 8 (API 26)+, ~Snapdragon 660 / 4 GB, 60 Hz | Stable play; no save loss; thermal run completed; draw-call debt explicitly assessed |
| Middle | Current mid-range, 90/120 Hz, 6–8 GB | 60 fps presentation target; audio/haptics/subtitles verified |
| Flagship | Current Android 16 device, 120 Hz | No high-refresh timing change; immersive/cutout transitions stable |
| Geometry | Narrow, tall, rounded corners, asymmetric punch-hole/notch | HUD, coach, subtitles, settings, credits, Count, and Ledger stay inside safe content |
| Navigation | Three-button and gesture navigation | Edge nudges/flippers/plunger work without trapped system gestures |

For each physical device record model, Android version, refresh rate, input mode, 30-minute
endgame temperature/battery delta, peak memory, peak draw calls, audio defects, and screenshots
of Attract, first Night, Count, Ledger, House Rules, and credits. The 486×864 automated fixture
uses asymmetric insets `44,96,72,54` plus a 56 px rounded-corner guard and remains mandatory.
