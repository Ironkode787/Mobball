# Meshes — proper toys for the 3D machine

> Status: pipeline live (`tools/meshgen/`), tier 1 shipped. Everything on the table used to be
> Godot primitives assembled in `_build_look()`; this spec lists what gets a real mesh, in
> what order, and the contract a mesh must meet so the code that drives it keeps working.

## 1. Rules

- **Colliders come first.** A mesh is dressing: it never changes a collider, a sensor or a
  position. Every piece keeps its primitive look as the fallback when its mesh is missing
  (`ToyLib.instance()` returns null and logs once — same contract as missing audio).
- **Source is code.** Meshes are generated by Blender scripts in `tools/meshgen/` and
  exported to `assets/meshes/<id>.glb` by `bash tools/meshgen/build.sh`. No binary is
  hand-edited; a change is a script change and a rebuild. Blender runs headless for the
  build; `tools/blender/serve.sh` + `.mcp.json` give an interactive Blender to iterate in.
- **Units and axes.** 1 Blender unit = 1 table unit = 10 cm. Blender is Z-up; the exporter
  converts to glTF Y-up, so Blender **−Y is the piece's front** (table +Z, the side the ball
  arrives from) and Blender +Z is up. The origin is the piece's pivot on the felt.
- **Palette.** PAPERBACK NOIR × ELECTRIC BRASS (docs/07): unsaturated matter — ink, steel,
  galvanised zinc, brass, rust, wood, rubber — and only earned light glows. Reserved colours
  (dirty red, clean green, heat, cop blue) are never decorative.
- **Budget.** GL Compatibility on low-end Android: ≤ 1 500 triangles for a hardware piece,
  ≤ 3 000 for a room toy, ≤ 400 for a repeated dressing prop. One material slot per surface
  type, flat or bevelled shading, no textures (colour comes from material albedo).
- **Node contract.** Mesh objects whose name starts with `Lamp` receive the piece's lamp
  material as `material_override` (emission stays code-driven); `Art*` objects receive the
  piece's decal material; any other naming a piece needs is listed below and enforced by the
  builder (`ToyLib.bind()` returns the number of nodes it matched).

## 3. Build & check

```
bash tools/meshgen/build.sh            # blender -b → assets/meshes/*.glb (+ preview PNGs)
bash tools/meshgen/build.sh sedan van  # a subset
/workspace/tools/godot/godot --headless --path . --import
```

`tools/meshgen/preview/` holds a Workbench render of every mesh from the player's angle for
review without booting the game. `tests/test_meshes.gd` asserts every tier-1 mesh exists,
loads, stays under budget and carries the nodes its piece binds.
