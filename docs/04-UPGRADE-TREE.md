# 04 — The Upgrade Tree ("The Ledger")

> **EVIDENCE PHOTO 44-C** — *A corkboard. Red string everywhere. In the center, a photograph
> of a pinball machine. Someone has written "HOW?" on it in grease pencil.*

The Ledger is a **corkboard conspiracy map pinned over a noir city map** ([07-ART](07-ART-DIRECTION.md) §4).
Upgrades are polaroids and index cards joined by red string; buying one pins it FLAT (stamped
"DONE") and pulls connected cards into view. Undiscovered branches are literally **face-down
cards** — you see string leading to *something*. Milestones flip whole clusters face-up at
once: the tree is also the game's suspense engine.

**Structure:** 6 branches × 8 tiers (T0–T7, gated by career rank R0–R7). ~130 nodes at launch.
**Costs:** clean cash; bands per tier listed in [03-ECONOMY](03-ECONOMY.md) §7. Repeatable
nodes (marked ↻) scale `base × 1.15^level`. **★ = loop-changer milestone** — an upgrade that
changes *how you play*, not just how much you earn. Every tier of every branch contains at
least one visible table change (pillar P1).

## Milestone reveals (the surprise engine)

Face-down clusters flip at scripted moments, always mid-Count with a stinger:

| Trigger | Reveal |
|---------|--------|
| First $10k held dirty (can't spend it) | the entire FRONTS branch — "you got a money problem, kid. A good one." |
| First TILT | Inspector's Coffee Fund line |
| First guy pinched twice in one Night | Juice Loans + Bail Bondsman |
| Reaching the Club deck the first time | casino cluster + Fight Night face-down teaser |
| Surviving first Raid | Rain Insurance + Police Scanner cluster |
| A briefcase SETUP fires | Know a Guy line ("never again, right?") |
| Beating 3rd Commission boss | The Rat's face-down card appears… with no string attached to it. (Dread.) |
| First Skip Town | the whole Black Book |

Design rule: **the player should never see the whole tree.** There is always at least one
face-down card with red string running off-screen. Even at 100%, one last card stays face-down
and unbuyable, labeled "RETIREMENT." (It flips on the day we ship the sequel or a v2.0 mode.)
